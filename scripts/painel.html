Painel do servidor de etiquetas

Tudo o que era feito pelo terminal, em botões. Os comandos saem direto desta página para o conector.

1. Chave de acesso

A chave fica só nesta aba do navegador e some quando a aba é fechada. Ela nunca é gravada no servidor nem enviada a outro lugar.

2. Situação das linhas

–versão
–linhas conectadas
–bloqueadas (403)
–sem pareamento

Informe a chave e clique em Conectar.

Linha pronta para etiquetar: conectada, com chaves, etiquetas maior que zero e sem bloqueio.

3. Testar etiqueta em uma conversa

Números de DDD acima de 30 costumam estar no WhatsApp sem o nono dígito (ex.: 554588286965, e não 5545988286965). Com o número errado o WhatsApp responde "ok" e nada aparece no celular.

4. Criar etiqueta em uma linha

O número interno é escolhido automaticamente (o próximo livre). O Backster já cria a etiqueta sozinho na primeira venda; use isto só para testar.
